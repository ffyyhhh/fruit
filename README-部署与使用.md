# 水果网站：部署与使用手册（零基础版）

> 代码已经写好了，你不需要改一行代码就能上线。
> 你只需要做三件事：**① 在电脑上看一眼 → ② 传到网上 → ③ 把占位信息换成你自己的。**
> 全程大约 30 分钟，不需要买服务器，不需要备案，不用花钱。

---

## 先认识这个文件夹

```
fruit-orchard/           ← 整个网站就是这一个文件夹
├── index.html           ← 页面内容（文字、价格、板块）
├── style.css            ← 颜色、排版、手机适配
├── script.js            ← 果篮、复制订单、打电话这些功能
└── assets/              ← 水果插图（6 个 svg + 1 个 logo）
```

**重要原则：这四个东西必须放在一起，`assets` 文件夹也要一起传。**
少一个，网页就会变得很难看或者功能失灵。

### 网站现在有什么

| 板块 | 作用 |
| --- | --- |
| 首屏 | 一句话卖点 + 两个按钮（看水果 / 复制微信） |
| 当季鲜果 | 6 个水果卡片，价格、产地、规格 |
| 为什么选我们 | 4 个信任点 |
| 果园故事 | 品牌故事 + 4 个数据 |
| 客户评价 | 3 条好评 |
| 下单流程 | 三步说明 |
| 果篮（点右上角） | 选水果 → 自动算钱 → 复制订单信息发微信 |

**为什么没有“在线支付”？**

因为在线收款需要营业执照、对公账户、支付接口，还要备案，个人做不了。
所以这个网站用的是**最实际的做法**：客户在网站上挑好水果，复制订单，发你微信，你收微信转账。
这也是大部分水果微商、社区团购在用的方式，转化率反而更高。

## 第一步：在电脑上看效果（1 分钟）

1. 打开 `fruit-orchard` 文件夹。
2. **双击 `index.html`**。
3. 浏览器打开了网页，地址栏是 `file:///C:/Users/...`。

这就说明网站是好的，只是还在你自己的电脑上。

顺手试三个功能：

- 点一个水果卡片上的 **加入果篮** → 右上角出现数字。
- 点右上角 **🧺 果篮** → 能加减数量、看到运费和合计。
- 点 **复制订单信息** → 屏幕下方弹出“已复制”，去微信里粘贴一下试试。

> ⚠️ 双击打开时，浏览器可能提示“已阻止不安全的内容”，忽略即可。
> 果篮里的东西会存在你浏览器里，**关掉再打开还在**，这是正常设计。

## 第二步：上线（二选一）

### 方案 A：Netlify Drop —— 5 分钟，不用注册（推荐第一次用）

这是目前对零基础最友好的方式：**把文件夹拖进网页，就有网址了。**

1. 打开 <https://app.netlify.com/drop>
2. 页面上有一个大虚线框，写着 “Drag and drop your site folder here”。
3. 打开你的文件资源管理器，把 **`fruit-orchard` 整个文件夹**按住鼠标左键，**拖进那个虚线框**。
   - 是拖文件夹，不是拖里面的文件。
4. 等 5～20 秒，页面变成一个绿色的 **Site deploy in progress → Published**。
5. 页面上会出现一个网址，长这样：

   ```
   https://sparkling-fudge-1a2b3c.netlify.app
   ```

6. **点这个网址**，你的网站就在互联网上了。用手机打开同一个网址试试。

**想换一个好记的网址？** 免费注册后，进入 Site settings → Change site name，改成
`guoyuan-xiansheng` 之类的，网址就变成 `https://guoyuan-xiansheng.netlify.app`。

**要记住**：Netlify 免费版不注册也能上线，但**不注册的站点一段时间后会被回收**。
所以看到网址后，建议花 1 分钟用邮箱注册一下，把这个站点“认领”下来。

> ✅ 优点：最快、自动 HTTPS、不用注册也能先看效果。
> ⚠️ 注意：在国内访问 `.netlify.app` 有时会慢一点，但一般能打开。

---

### 方案 B：GitHub Pages —— 更稳、可以长期更新（推荐正式用）

GitHub 是全球最大的代码托管网站，Pages 是它送的免费网站空间。稍微多几步，但更专业。

**1. 注册账号**

打开 <https://github.com/signup>，用邮箱注册。
用户名会出现在网址里（`用户名.github.io`），**想好再填**，比如 `xiaolin-fruit`。

**2. 新建仓库**

登录后，点右上角的 **`+`** → **New repository**。

- **Repository name**：填 `fruit`
- 下面选 **Public**（免费账号的 Pages 只支持公开仓库）
- 其他都不用管，点最下面的绿色按钮 **Create repository**

**3. 上传文件（这一步最容易错，看清楚）**

1. 在新页面上找到一行蓝色小字 **uploading an existing file**，点它。
2. 打开你的 `fruit-orchard` 文件夹，**按 `Ctrl + A` 全选里面的 4 项**
   （`index.html`、`style.css`、`script.js`、`assets` 文件夹，**不要选 fruit-orchard 这个外壳文件夹**）。
3. 把它们拖进网页中间的虚线框。
4. 等文件列表出现（应该看到 3 个文件 + 1 个 assets 文件夹），
   在最下面点绿色按钮 **Commit changes**。

> 上传成功的标志：仓库首页能看到 `index.html` 在**最外层**，点进 `assets` 能看到 7 个 svg。
> 如果看到的是 `fruit-orchard/index.html`，说明多套了一层，网址会变成 `.../fruit/index.html`，需要删掉重传。

**4. 打开 Pages 开关**

1. 仓库页面上方一排标签里，点 **Settings**（齿轮图标）。
2. 左边栏往下找，点 **Pages**。
3. 在 “Build and deployment” 下面：
   - **Source** 选 `Deploy from a branch`
   - **Branch** 选 `main`，右边文件夹选 `/ (root)`
   - 点 **Save**
4. 等 1～2 分钟，刷新这个页面，顶部会出现一行：

   ```
   Your site is live at https://你的用户名.github.io/fruit/
   ```

5. 点进去，网站上线了。

> ✅ 优点：永久免费、更新方便、网址稳定。
> ⚠️ 注意：国内访问 `github.io` 时不时会慢或打不开，主要给国内客户看的话建议用方案 A 或者后面的域名方案。

---

### 两个方案怎么选

| | Netlify Drop | GitHub Pages |
| --- | --- | --- |
| 上手难度 | ⭐ 拖一下就完事 | ⭐⭐⭐ 要注册、建仓库 |
| 上线速度 | 20 秒 | 5 分钟 |
| 以后更新 | 再把文件夹拖一次 | 上传新文件，自动更新 |
| 国内访问 | 一般 | 时快时慢 |
| 适合 | 先看效果、临时用 | 长期正式用 |

**建议**：先用 A 上线，拿着网址发给朋友看；觉得可以了，再用 B 做一个正式的。

## 第三步：上线立刻做的 3 件事

1. **用手机打开网址**，从头滑到底。重点检查：水果图片有没有出来、果篮能不能点开、电话能不能拨。
2. **把网址变成二维码**。打开 <https://cli.im>（草料二维码），粘贴你的网址，生成二维码，下载图片。
   这张图可以贴在名片、包装箱、朋友圈海报上。
3. **发一条朋友圈**测试：文案 + 二维码 + 网址。

## 第四步：改成你自己的店（15 分钟）

现在页面上的电话、微信、地址、价格都是**示例**，一定要改，否则客户联系不上你。

### 4.1 改电话 / 微信 / 地址（只改一个地方）

用记事本或 VS Code 打开 **`script.js`**，最上面有一块：

```js
const SHOP = {
  name: '果园鲜生',
  phone: '138-0000-0000',      // 显示用的电话
  phoneRaw: '13800000000',     // 打电话用的号码（去掉横线）
  wechat: 'guoyuan-fresh',     // 客服微信号
  address: '云南省昆明市呈贡区',
};
```

- `phone` 改成你想显示的样子，比如 `139-8888-6666`
- `phoneRaw` 改成同一个号码，但**去掉所有横线**，比如 `13988886666`（这决定了客户点电话能不能拨出去）
- `wechat` 改成你的微信号
- 改完按 `Ctrl + S` 保存，刷新网页，页面上所有地方的电话微信都变了

### 4.2 改水果、价格、产地

打开 **`index.html`**，按 `Ctrl + F` 搜索水果名，比如 `赣南脐橙`，你会看到这样一段：

```html
<h3>赣南脐橙</h3>
<p class="origin">江西赣州 · 5 斤装</p>
<div class="price"><strong>¥39.9</strong><del>¥49.9</del></div>
<button class="add-btn" ... 
  data-id="orange" data-name="赣南脐橙" data-spec="5 斤装" data-price="39.9">
```

改四处，**一定要一起改**：

| 改哪里 | 作用 |
| --- | --- |
| `<h3>赣南脐橙</h3>` | 卡片上显示的名字 |
| `<p class="origin">` | 产地 + 规格 |
| `<strong>¥39.9</strong>` | 现价 |
| `data-name` / `data-spec` / `data-price` | 加进果篮后用的名字、规格、价格（**算钱用的是这个**） |

> 如果只改了显示的价格，没改 `data-price`，客户看到的和算出来的钱会不一样。
> 这是最容易出错的地方，改完一定要点“加入果篮”验证一下。

**不想要某个水果**：把那一整个 `<article class="product reveal"> ... </article>` 删掉就行，从 `<article` 到 `</article>` 整段删。

### 4.3 换成真实照片（强烈建议）

现在的图是我画的矢量插画，干净但不如真照片有食欲。

1. 准备 6 张正方形照片（建议 800×800 像素以内，太大加载慢）。
2. 改名为 `orange.jpg`、`strawberry.jpg`、`grape.jpg`、`mango.jpg`、`peach.jpg`、`blueberry.jpg`。
3. 放进 `assets` 文件夹。
4. 在 `index.html` 里把所有 `assets/orange.svg` 改成 `assets/orange.jpg`，以此类推。
   （`Ctrl + H` 批量替换最快）

> 手机拍的照片也能用，但一定要**先裁成正方形**，否则卡片里会被压扁。

### 4.4 改店名和备案号

- 店名 `果园鲜生`：出现在导航、页脚、标题里，用 `Ctrl + H` 全部替换。
- 页脚的“京 ICP 备 00000000 号”：如果你以后用国内服务器，这里是放备案号的地方；
  用 Netlify / GitHub Pages 不需要备案，可以把这行删掉。

### 4.5 改完记得重新上线

**改本地文件，线上不会自动变。** 必须再传一次：

- **Netlify**：重新打开 <https://app.netlify.com/drop> 拖一次文件夹（登录状态下会覆盖同一个站点）。
- **GitHub**：进仓库 → Add file → Upload files → 上传改过的文件 → Commit。

传完等 1 分钟，然后**在手机上强制刷新**（或者关掉页面重开）再看。

## 第五步：怎么真正“用起来”

网站上线只是有了一个“门面”，真正的成交发生在微信里。完整流程是这样的：

```
客户看到你的朋友圈 / 二维码
        ↓
打开网站，看水果和价格
        ↓
点“加入果篮”，挑好几样
        ↓
点“复制订单信息”
        ↓
把这段文字 + 姓名电话地址 发给你的微信
        ↓
你确认库存 → 报运费 → 客户微信转账
        ↓
你当天采摘、打包、发顺丰
        ↓
把快递单号发给客户
```

**客户发来的订单信息长这样**（网站自动生成的）：

```
【果园鲜生】果篮订单
----------------
1. 赣南脐橙（5 斤装）× 2　¥79.80
2. 丹东草莓（2 斤装）× 1　¥68.00
----------------
商品小计：¥147.80
运费：¥0.00（包邮）
合计：¥147.80

收货人：
手机号：
收货地址：
```

你收到后，只要回复三句话就能成单：

> 收到 ✅ 一共 147.8 元，包邮。
> 今天下午采摘，明天发出，后天到。
> 麻烦把收货人、电话、地址发我一下～

**提高转化的 5 个小动作**：

1. 首屏那行字（“把果园的甜 24 小时送到家”）可以按季节换，比如夏天换“冰镇一箱，整个夏天都甜”。
2. 每周三真的上新一次，把最上面那张卡换成新到的水果。
3. 客户好评截图发给你，就加到“他们说”那一栏里（改 `index.html` 里的三条评价）。
4. 二维码印在包装箱上，吃得好的人会扫码复购。
5. 满 99 包邮是故意设的门槛——客户为了包邮会多买一样，这是最有效的提客单价方法。

## 第六步：出问题了怎么办

| 现象 | 原因 | 怎么修 |
| --- | --- | --- |
| 双击打开是一片空白 | 文件没下载全 | 确认 `index.html`、`style.css`、`script.js`、`assets` 四个都在同一层 |
| 水果图片显示成一个破图标 | `assets` 文件夹没上传，或图片改名了 | 检查路径 `assets/xxx.svg` 和实际文件名是否一致（**大小写也要一致**） |
| 页面能打开，但没有颜色、排版全乱 | `style.css` 没上传 | 回到仓库看根目录有没有 `style.css` |
| 点“加入果篮”没反应 | `script.js` 没上传，或浏览器太老 | 按 `F12` → Console 看红色报错 |
| 改了线上没变化 | 浏览器缓存，或忘了重新上传 | `Ctrl + F5` 强制刷新；确认真的重新部署了 |
| 网址打开是 404 | `index.html` 不在仓库最外层 | 把文件移到根目录，或网址加上 `/fruit/` 这样的子路径 |
| 手机上字特别小 | 少了 viewport（这版已经有了） | 确认 `<head>` 里有 `width=device-width` 那行 |
| 微信里打开提示“非官方网页” | 微信对外链的安全提示 | 正常现象，点“继续访问”即可；长期做建议用备案域名 |

**万能排查**：电脑上打开网页，按 `F12`，点 **Console**。
红色的字就是错误原因，把内容复制给懂技术的人（或者发给我），一眼就能看出来。

## 第七步（可选，以后再做）：绑定自己的域名

`https://guoyuan-xiansheng.netlify.app` 能用，但印在包装箱上不够正式。
买个域名 `guoyuan.com` 大约 60～90 元/年。

1. 在阿里云 / 腾讯云 / Cloudflare 买域名。
2. **Netlify**：Site settings → Domain management → Add custom domain → 填你的域名 → 按提示去域名商加一条 CNAME 记录。
3. **GitHub Pages**：Settings → Pages → Custom domain 填域名；DNS 里加 CNAME 指向 `用户名.github.io`。
4. 等几分钟到几小时生效，Netlify 和 GitHub 都会自动给你配好 HTTPS。

> 用国外服务器（Netlify / GitHub / Vercel）**不需要 ICP 备案**。
> 如果你以后换到阿里云、腾讯云的国内服务器，就**必须备案**，否则 80 端口会被拦。
